# MDict test fixtures

`tiny.mdx` and `tiny.mdd` are generated by `generate_mdict_fixtures.py` in this
directory and committed so the application format matrix can convert a real
MDict container without a third-party sample.

- Content: three English headwords with one generated HTML article each
  (`tiny.mdx`) and two generated resources (`tiny.mdd`).
- Provenance: written by this repository's own generator from the published
  engine-2.0 layout; no text, image or other material from a third-party
  dictionary is included.
- License: the same MIT grant as the rest of this repository.
- Regenerate with `python generate_mdict_fixtures.py`; the writer is
  deterministic, so the bytes should not change unless the writer changes.

The C test `tests/mdict_test.c` builds its own containers in memory and does
not read these files; they exist for the CLI-level format matrix.
